# Legendary Blacksmith

A React + Vite starter repo for a gaming web app with a fantasy forge landing screen.

## Scripts

- `npm install`
- `npm run dev`
- `npm run build`
- `npm run preview`

## GitHub Pages Deployment

- `npm run deploy`

Notes:
- This repository uses Vite `base: '/legendary-blacksmith/'` for Pages.
- The deploy script publishes `dist` to the `gh-pages` branch.
